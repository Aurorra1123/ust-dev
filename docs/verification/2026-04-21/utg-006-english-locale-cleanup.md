# UTG-006 英文模式中文残留收口验证

## 变更目标

- 清理英文模式下仍会直接显示中文的固定界面文案。
- 让核心学生页与后台工作区的按钮、标题、表单反馈、placeholder 与日期格式跟随当前语言切换。

## 实施摘要

- 登录页品牌标题已接入双语切换，不再在英文模式固定显示中文副标题。
- 资源、通知、规则、活动工作区的创建表单已移除中文预填示例内容：
  - 资源创建
  - 资源单元创建
  - 通知创建
  - 新建规则
  - 新建活动 / 新增票种
- 资源工作区中仍残留的硬编码标题、placeholder、成功提示与提交按钮文案已全部接入双语。
- 共享日期工具 `apps/web/src/lib/date.ts` 已改为默认跟随当前 `locale`，空值文案也同步随语言切换。
- 清空默认示例内容后，相关创建按钮已补充最小禁用条件，避免表单退化为可提交空值状态。

## 关键决策

- 前端日期格式化默认跟随当前语言，不再固定为 `zh-CN`。
- 该决策已沉淀为 ADR：
  - `docs/adr/0012-locale-aware-frontend-date-formatting.md`

## 本地校验

- `pnpm --filter web lint`
- `pnpm --filter web typecheck`
- `pnpm --filter web build`

## 构建结果

- 本地 `web` 构建通过，最新产物为：
  - `dist/assets/index-DDfSmNxP.js`

## 结论

- 英文模式下，核心学生页与后台关键工作区的固定界面文案已不再意外显示中文。
- 日期、时间与“未设置”类空值文案已跟随当前语言统一收口。
- 用户输入内容、已有业务正文或种子数据文本仍允许保留其原始语言，不纳入本轮清理范围。
