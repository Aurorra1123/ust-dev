# UTG-013 学生端共享壳层英文残留清理验证

## 变更目标

- 清理学生端共享壳层在英文模式下仍固定显示中文的问题。
- 让 `/spaces`、`/activities`、`/service-requests` 等复用同一壳层的页面，不再因为公共头部文案而被误判为“英文版没做完”。

## 实施摘要

- 已确认第二轮用户反馈中的英文中文残留主要来自 `apps/web/src/ui/app-shell.tsx`，不是页面主体文案普遍未接入双语。
- 顶部品牌标题已改为通过 `localeText` 跟随当前语言：
  - 中文模式显示 `CampusBook 智约校园`
  - 英文模式显示 `CampusBook`
- 语言切换按钮已改为跟随当前语言显示：
  - 中文模式显示 `中文 / 英文`
  - 英文模式显示 `Chinese / English`
- 本轮未改动导航结构、登录恢复提示、路由行为或任何 API 链路。

## 本地校验

- `pnpm --filter web lint`
- `pnpm --filter web typecheck`
- `pnpm --filter web build`

## 结论

- 学生端共享壳层的英文固定中文残留已收口。
- 英文模式下，学术空间、活动、报修工单等页面不再通过顶部共享壳层固定显示中文品牌副标题或 `中文` 按钮字样。
- 若后续仍有“英文页出现中文”的反馈，应优先区分：
  - 共享壳层与固定界面文案
  - 用户输入或 seed 数据正文
