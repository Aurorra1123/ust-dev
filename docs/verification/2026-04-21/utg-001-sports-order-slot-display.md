# UTG-001 体育预约离散时段订单展示修正验证

## 变更目标

- 修正体育预约在订单列表与订单详情中的时间文案。
- 多个非连续槽位应按离散时段展示，而不是被压成一个连续区间。

## 实施摘要

- 前端订单展示层改为基于 `sportsReservationSlots` 做去重和离散时段归并。
- 组合场地模式下，同一时间槽位因多场地重复产生的时间段不会重复展示。
- 体育订单进度状态改为按真实离散时段判断，避免在两个预约时段中间的空档误显示为“进行中”。

## 本地校验

- `pnpm --filter web lint`
- `pnpm --filter web typecheck`
- `pnpm --filter web build`

## 结果

- 订单详情页的“时间”字段现可展示多个离散预约时段。
- “我的订单”列表卡片现直接展示预约时间，不再只能看到下单时间。
- 相邻连续槽位仍会合并显示为单段时间，非连续槽位会分段显示。
