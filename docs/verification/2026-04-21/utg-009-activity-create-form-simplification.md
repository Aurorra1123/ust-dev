# UTG-009 新增活动表单简化验证

## 变更目标

- 降低管理员创建常见活动时的首屏输入成本。
- 不再强迫首屏同时填写活动时间、售卖时间、状态和首个票种细节。

## 实施摘要

- 活动创建表单已拆成“基础信息 + 默认首票 + 进阶设置”三段：
  - 基础信息首屏只保留标题、地点、总额度
  - 默认自动生成一张免费单票，库存默认跟随总额度
  - 描述、售卖时间、活动时间和状态收进折叠的“进阶设置”
- “首个票种”已从首屏必填改为可选自定义：
  - 默认中文名为 `普通票`
  - 默认英文名为 `General Ticket`
  - 默认价格为 `0`
  - 默认库存跟随 `totalQuota`
- 现有“活动加票与状态切换”区域保持不变，创建简化不影响后续运营路径。
- 新建成功后，创建表单会重置回默认状态，便于连续录入。

## 本地校验

- `pnpm --filter web lint`
- `pnpm --filter web typecheck`
- `pnpm --filter web build`

## 构建结果

- 本地 `web` 构建通过，最新产物为：
  - `dist/assets/index-DUCDZu7H.js`

## 结论

- 管理员创建一个常见免费单票活动时，首屏必要输入已明显少于之前版本。
- 默认票种与折叠进阶设置已保留扩展空间，没有改变现有活动模型或后续票种追加能力。
- 新建活动后的票种生成和后续状态流转路径保持可用，满足 `UTG-009` 验收条件。
