# UTG-002 / UTG-003 管理端删除能力与规则工作区验证

## 变更目标

- 为管理员补齐资源、资源单元与规则的安全停用 / 删除能力。
- 将规则工作区从快照页升级为可配置工作区。

## 实施摘要

- 资源工作区新增：
  - 资源启用 / 停用
  - 资源安全删除
  - 资源单元安全删除
  - 删除失败原因提示与确认弹窗
- 规则工作区新增：
  - 规则创建、编辑、启停
  - 规则与资源绑定 / 解绑
  - 规则安全删除
  - 写操作的进行中、成功、失败反馈
- 后端新增：
  - 资源删除接口
  - 资源单元删除接口
  - 规则解绑接口
  - 规则删除接口

## 关键策略

- 资源与规则优先采用启停，不直接鼓励物理删除。
- 资源、资源单元、规则只有在无危险引用时才允许删除。
- 对仍有关联记录的对象会阻止删除，并返回明确原因。

## 本地校验

- `pnpm --filter api lint`
- `pnpm --filter api typecheck`
- `pnpm --filter api build`
- `pnpm --filter web lint`
- `pnpm --filter web typecheck`
- `pnpm --filter web build`

## 结果

- 管理员不再只能查看规则快照，而可以直接配置规则并绑定资源。
- 资源、资源单元、规则都已有最小可用的撤销错误配置入口。
- 危险操作已带确认，写操作在规则与资源工作区中具备可见反馈。
