# UTG-005 体育组合预订语义收口验证

## 变更目标

- 让用户在进入体育组合预订模式时，能够明确理解该模式会同时预约哪些场地，以及何时应该使用它。
- 保留后端组合预约能力，但不继续让前端把它暴露成一个缺乏解释的模糊切换。

## 实施摘要

- 体育页现在只在当前资源存在组合数据时显示“组合预订”入口。
- 组合目标下拉项已从“几个场地单元”调整为成员场地摘要，例如 `Court A、Court B`。
- 组合模式右侧已新增说明卡，明确展示：
  - 当前组合的描述或用途
  - 组合包含的成员场地
  - 选择一个时段会同时锁定整组场地
  - 任一成员场地冲突、进行中或关闭时，该时段不可选
- 提交区已新增“提交效果”提示，避免用户误以为自己只是在预约其中一个场地。

## 本地校验

- `pnpm --filter web typecheck`

## 结论

- 已形成明确产品结论：组合预约能力继续保留，但以前端带解释的次级模式呈现。
- 当前界面已能清楚说明组合包含哪些场地、会锁定什么，以及为什么某些时段不可选，满足 `UTG-005` 的核心验收目标。
- 没有组合数据的资源不再显示该模式入口，避免继续制造理解噪音。
