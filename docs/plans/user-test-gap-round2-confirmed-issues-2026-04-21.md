## 3. 问题卡

### UTG-011 学术空间零单元资源导致时间轴空白

- 用户反馈：
  - `https://campusbook.top/spaces` 中，“创新协作室”的可视化时间轴没有正常加载。
- 当前核对结果：
  - 线上公共资源接口 `https://api.campusbook.top/resources?type=academic_space` 返回的“创新协作室”当前 `unitCount` 为 `0`，`units` 为空数组。
  - 对应预约状态接口可正常返回，通道状态为 `open`，并不是接口报错或时间轴组件崩溃。
  - 当前前端时间轴是按资源单元逐行渲染的；当资源没有任何单元时，中间区域没有可绘制的时间轴行，用户会直接感知为“没有加载出来”。
- 根因判断：
  - 根因 1：线上演示数据不完整，“创新协作室”被发布到学生侧，但没有配置任何可预约单元。
  - 根因 2：学生端缺少“零单元资源”的明确空状态说明，导致空白视图被误判为加载失败。
- 影响范围：
  - 学术空间学生端页面
  - 线上演示数据与资源发布质量
  - 管理端资源配置完整性的可观测性
- 修改方案：
  1. 学术空间学生端为“当前资源没有可预约单元”增加明确空状态，不再出现中间视图区近似空白的表现。
  2. 对线上演示数据做补齐：
     - 要么给“创新协作室”补至少一个真实资源单元；
     - 要么在未配置单元前不向学生侧公开该资源。
  3. 管理端资源工作区增加配置完整性提醒：
     - 当资源 `units.length === 0` 时，给出明显提示，提醒管理员该资源当前不会在学生侧形成可预约时间轴。
- 验收标准：
  - 学术空间页面选择零单元资源时，会出现明确说明，而不是让用户误判为加载失败。
  - “创新协作室”在线上环境中要么具备可见时间轴，要么不再作为面向学生的可预约资源展示。
  - 管理端能明确识别“已创建资源但未配置单元”的不完整状态。

### UTG-012 管理端预约关闭规则缺少撤销入口

- 用户反馈：
  - 管理员增加预约关闭规则后，无法取消。
- 当前核对结果：
  - 后端资源控制器当前只提供：
    - `POST /admin/resources/closures`
    - `PATCH /admin/resources/closures/:id`
  - 没有删除关闭规则的接口。
  - 前端资源工作区当前可以新增关闭规则，也能展示已有关闭规则，但没有删除或撤销按钮。
- 根因判断：
  - 这是一个完整的后台能力缺口，不是前端单点显示问题。
  - 当前系统允许“创建关闭规则”，但没有提供对称的“撤销关闭规则”路径，导致运营操作不可逆。
- 影响范围：
  - 管理端资源工作区
  - 资源通道关闭策略维护
  - 演示环境与真实运营环境的可恢复性
- 修改方案：
  1. 后端补充删除接口：
     - 增加 `DELETE /admin/resources/closures/:id`
     - 写服务补充存在性校验与删除返回值
  2. 前端资源工作区在每条关闭规则卡片上增加“删除 / 撤销”操作按钮。
  3. 删除前加入确认弹窗，明确说明影响。
  4. 删除后刷新资源列表、资源状态和关闭规则展示区域。
  5. 为该操作补成功/失败提示，保持与现有 `MutationState` 体验一致。
- 验收标准：
  - 管理员可删除一条已创建的预约关闭规则。
  - 删除后资源工作区中的关闭规则列表与资源状态能即时刷新。
  - 危险操作有确认提示，删除结果有成功/失败反馈。

### UTG-013 学生端共享壳层在英文模式下仍显示中文

- 用户反馈：
  - `study / activities / service_request` 英文版本仍有中文。
- 当前核对结果：
  - 上述三个学生端页面都挂在共享壳层 `apps/web/src/ui/app-shell.tsx` 下。
  - 该壳层顶部品牌文案此前固定为 `CampusBook 智约校园`，不会随 `locale` 切换。
  - 语言切换入口中的中文按钮此前固定显示 `中文`，英文模式下也会直接看到中文字样。
- 根因判断：
  - 问题不在 `spaces`、`activities`、`service-requests` 三个页面主体，而在它们共用的页面壳层没有把品牌与语言切换文案完全接入双语。
  - 这会让用户误判为这些英文页面本身仍未完成国际化，即使主体内容已基本切到英文。
- 影响范围：
  - 学生端共享导航壳层
  - 学术空间、活动、报修工单及其他复用该壳层的学生页
- 修改方案：
  1. 将学生端顶部品牌文案接入 `localeText`，英文模式不再固定显示中文副标题。
  2. 将语言切换按钮文本改为随当前语言切换，避免英文界面继续露出固定 `中文` 字样。
  3. 保持导航、登录恢复提示和当前语言切换行为不变，只收口文案边界。
- 验收标准：
  - 英文模式下学生端公共壳层不再固定显示 `智约校园`。
  - 英文模式下语言切换入口不再固定显示 `中文`。
  - 壳层改动不会影响原有导航与双语切换能力。
