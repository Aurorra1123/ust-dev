# 0011 学术空间可用性视图采用连续时间轴而非离散槽位表

## 背景

`UTG-004` 需要为学术空间预约补齐“先看可用性，再提交预约”的可视化能力。

现有系统里：

- 体育设施采用离散 1 小时槽位模型
- 学术空间采用连续时间预约模型，用户直接输入开始时间与结束时间

如果直接把体育页的时段表格复刻到学术空间页，会出现两个问题：

1. 展示模型与实际预约模型不一致，容易让用户误以为学术空间也只能按固定槽位预约
2. 为了迁就表格而引入额外的离散化逻辑，会把连续预约边界复杂化，增加误导和维护成本

当前更合理的目标不是“所有资源都用同一张网格”，而是“让可视化方式忠实表达各自的预约语义”。

## 决策

本项目后续对学术空间预约采用以下方案：

1. 学术空间可用性视图使用连续时间轴
2. 资源单元按行展示，预约占用、关闭区间和当前选择按时间比例映射到时间轴上
3. 体育设施继续保留离散槽位表，不强行与学术空间统一为同一种交互
4. 学术空间表单继续保留开始时间 / 结束时间输入，但必须和时间轴联动，避免重新退化为“盲提表单”

## 明确不采用的方案

本轮明确不采用以下做法：

- 直接把体育页的固定槽位表复制到学术空间页
- 为了前端展示统一，而把学术空间连续模型强行离散化
- 只在表单提交失败后告诉用户冲突，而不提供提交前可视化

这些方案的问题在于：

- 会把连续预约的业务语义扭曲成离散槽位
- 会让“看起来统一”的 UI 掩盖实际规则差异
- 会继续保留用户测试里指出的低效决策路径

## 影响

正向影响：

- 学术空间页面的可视化方式与后端连续时间模型保持一致
- 用户能先看占用和关闭区间，再决定开始与结束时间
- 体育与学术两类资源各自保留更符合业务的交互表达，不做伪统一

需要注意的影响：

- 后续如果继续扩展学术空间视图，应优先增强连续时间轴能力，而不是回到槽位表
- 若未来引入按半小时或更细粒度的辅助标尺，也应仅作为连续时间轴的参考，而不是改变预约模型本身

## 后续动作

1. 若后续继续增强学术空间体验，可补“自动吸附到最近可用边界”或“快捷选择推荐时长”
2. 若其他连续时间资源类型出现，默认复用连续时间轴方案，而不是复制体育页的离散槽位表
