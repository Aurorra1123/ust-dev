# ADR 0006: Expose A Masked Resource Reservation Status Endpoint For Student Schedule Views

## Status

Accepted

## Context

`PUX-009` 需要把学生端体育预约页重构为“资源信息 + 时间表 + 状态说明”的前端原型。中间的时间表必须真实展示哪些时段可预约、哪些已占用、哪些正在进行中。

仓库原有的资源状态接口只有管理员侧 `admin/resources/:id/reservation-status`。该接口会返回：

- 预约用户邮箱
- 订单号
- 参与人数等管理信息

这些字段足够支撑后台运营，但不适合直接暴露给学生端页面。

## Decision

新增一个面向学生端时段视图的脱敏只读接口：

- 路径：`/resources/:id/reservation-status`
- 返回内容保留：
  - 资源名
  - 查询时间范围
  - 通道状态
  - 关闭时段
  - 资源单元级预约占用记录
  - 参与人数与签到人数
- 返回内容去掉：
  - 用户邮箱
  - 用户 ID
  - 订单号
  - 其他后台运营所需的身份信息

前端体育预约页只使用该脱敏接口绘制时段表格，不再依赖管理员接口或伪造静态占用数据。

## Consequences

- 学生端可以基于真实数据展示时段占用和进行中状态
- 预约时段表保持必要的业务可见性，同时避免泄露他人身份信息
- 管理端与学生端的预约状态接口边界更加清晰
- 若后续需要更细粒度的学生端可见字段，应继续在脱敏接口上扩展，而不是复用管理员接口
