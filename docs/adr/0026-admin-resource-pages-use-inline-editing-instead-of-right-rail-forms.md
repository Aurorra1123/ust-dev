# ADR 0026: 管理员资源页改用就地编辑而不是右侧栏表单

## 背景

管理员端的体育场馆与学术空间页面已经逐步收口为资源维护页，但当前交互仍然延续了“选中对象后，到右侧栏操作”的模式。

这带来 3 个持续问题：

1. 用户需要先理解“当前选中了谁”，再去另一块区域填写表单。
2. 资源、资源单元和新增入口分散在不同区域，容易丢失上下文。
3. 页面越往后加功能，右侧栏越容易再次膨胀成大表单区。

## 决策

确认以下交互边界：

1. 体育场馆与学术空间页不再以右侧栏作为主要 CRUD 交互区。
2. 已存在的资源与资源单元采用对象就地编辑：
   - 资源卡片就地编辑
   - 资源单元行内编辑或附着式展开编辑
3. 新增入口采用虚线框样式：
   - 资源列表末尾的 `新增资源`
   - 当前资源单元列表底部的 `新增资源单元`
4. 删除、启停、保存等操作按钮应贴着当前对象出现，而不是要求用户切换到另一栏。

## 影响

正面影响：

- 用户更容易理解“我在改谁”
- 页面注意力流更稳定
- 教师端更像后台管理页，而不是控制台

需要注意的影响：

- 页面需要重新组织资源卡片与资源单元列表的展开状态
- 行内编辑要兼顾移动端和小屏可读性
- 成功、失败、处理中反馈仍需保留，不能因为表单内联化而消失

## 后续动作

1. 在 `ADM-010` 中落实资源页交互重构。
2. 保持 `ADM-008` 已完成的基础 CRUD 与字段说明，不做回退。
3. 实现时同步收口按钮文案、空态和删除确认提示，避免只是换位置不换体验。
